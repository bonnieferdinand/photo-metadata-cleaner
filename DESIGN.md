# Design direction

Photo Metadata Cleaner is a utility, not a product launch. People arrive with a photo they are about to post and want it clean in a few seconds, most often on a phone.

- **Identity:** a careful tool. Calm, precise and honest about what it can and can't do.
- **Personality:** a lab bench, not a marketing page. Labels say what they mean; numbers are real file sizes and counts.
- **Palette:** cool grey paper, ink-dark text, one blue for actions. Category colors (AI = rose, location = orange, camera/personal = amber, clean = green) are signals and appear only on findings.
- **Typography:** the device's own system fonts, so nothing has to download. Headings are heavy and tight; file data is set in the system monospace.
- **Layout:** phone first. The primary action sits where a thumb reaches. Larger screens get more room, not more decoration.
- **Mood:** quiet. No glow, gradients, badges or looping motion.

Dial: ENERGY 1 / RHYTHM 2 / MOTION 1
